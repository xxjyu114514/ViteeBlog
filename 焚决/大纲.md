## 🎬 模块 4：动画系统

### 4.1 动画实现方式

**技术栈**：原生 **Web Animations API** (`element.animate()`)
- 不依赖第三方动画库
- 不使用 CSS `transition` 或 `animation` 进行页面切换动画
- 通过 JavaScript 精确控制动画时序和状态

### 4.2 触发位置

**根组件**：`App.vue`

```vue
<router-view v-slot="{ Component, route }">
  <transition 
    @enter="onTransitionEnter" 
    @leave="onTransitionLeave" 
    :css="false"
  >
    <component 
      :is="Component" 
      :key="route.path" 
      :class="['page-wrapper-base', { 
        'padding-page': !isImmersivePage, 
        'card-page': route.meta?.noCardTransition 
      }]" 
    />
  </transition>
</router-view>
```

**逻辑委托**：`App.vue` 调用 [usePageTransition()](file://d:\project\ViteeBlog\frontend\src\composables\usePageTransition.js#L6-L75) composable，实际的动画逻辑在 `composables/usePageTransition.js` 中实现。

### 4.3 方向判断逻辑

**判断依据**：路由 `meta.index` 数值比较

```javascript
const getIndex = (route) => route?.meta?.index ?? 0
const isBackward = toIndex < fromIndex  // 目标 index < 来源 index = 后退
```

**动画策略**：

| 方向 | Enter 动画（新页面进入） | Leave 动画（旧页面离开） |
|------|------------------------|------------------------|
| **前进** (`toIndex > fromIndex`) | `clipPath: inset(0 0 0 100%) → inset(0 0 0 0%)`<br/>从右向左展开 | `opacity: 1 → 0.6`<br/>淡出 |
| **后退** (`toIndex < fromIndex`) | `opacity: 0.8 → 1`<br/>淡入 | `clipPath: inset(0 0 0 0%) → inset(0 0 0 100%)`<br/>从右向左收缩 |

**层级控制**：
- 前进动画：新页面 `z-index: 10`，旧页面 `z-index: 1`
- 后退动画：新页面 `z-index: 1`，旧页面 `z-index: 10`

### 4.4 动画参数配置

```javascript
const animOptions = {
  duration: 800,           // 800ms 持续时间
  easing: 'cubic-bezier(0.645, 0.045, 0.355, 1)',  // 缓动函数
  fill: 'forwards',        // 保持最终状态
}
```

### 4.5 跳过动画的条件

**条件判断**（在 `App.vue` 中）：

```javascript
const hasCardTransition = (r) => r?.meta?.noCardTransition

const onTransitionEnter = (el, done) => {
  // 如果目标或来源路由有 noCardTransition，跳过动画
  if (hasCardTransition(route) || hasCardTransition(router.currentRoute.value)) {
    done(); return
  }
  onEnter(el, done)
}
```

**跳过动画的路由**（设置了 `noCardTransition: true`）：
- `/manage-articles`（文章管理）
- `/edit-article`（文章编辑）
- `/edit-article/:id`（文章编辑）
- `/favorites`（我的收藏）
- `/social`（社交关系）

**沉浸式页面特殊处理**：
```javascript
const isImmersivePage = computed(() => {
  const immersiveRoutes = ['home', 'posts-immersive', 'about-immersive', 'message-immersive']
  return immersiveRoutes.includes(route.name)
})
```
- 沉浸式页面不应用 `padding-page` 类
- 但仍然有页面切换动画（除非设置 `noCardTransition`）

### 5.3 认证状态判断方式

**计算属性**：

```javascript
// 是否已登录
const isAuthenticated = computed(() => !!token.value)

// Token 是否有效（未过期）
const isTokenValid = computed(() => {
  if (!token.value) return false
  try {
    const payload = JSON.parse(atob(token.value.split('.')[1]))
    return payload.exp * 1000 > Date.now()  // 过期时间 > 当前时间
  } catch {
    return false
  }
})

// 是否为管理员
const isAdmin = computed(() => userInfo.value?.role === 'admin')
```

### 5.4 状态操作

```javascript
// 设置认证信息（登录成功后调用）
function setAuth(accessToken, user) {
  token.value = accessToken
  userInfo.value = user
  localStorage.setItem('vitee_token', accessToken)
  localStorage.setItem('vitee_user', JSON.stringify(user))
}

// 清除登录状态（退出登录调用）
```

## 📊 总结

### 项目技术栈

| 分类 | 技术 | 版本/说明 |
|------|------|----------|
| **前端框架** | Vue 3 | Composition API + `<script setup>` |
| **构建工具** | Vite | 快速开发服务器 + HMR |
| **状态管理** | Pinia | 轻量级、类型友好 |
| **路由** | Vue Router 4 | History 模式 |
| **网络请求** | 原生 Fetch | 自定义封装（api/client.js） |
| **样式预处理器** | SCSS | 分层架构（tokens/mixins/views） |
| **Markdown 编辑器** | Vditor | 即时渲染模式（IR） |
| **动画** | Web Animations API | 原生 JS，无第三方库 |

### 核心设计原则

1. **组件化**：功能模块独立封装，避免直接修改原有文件
2. **分层架构**：`api → services → composables → views` 清晰分离
3. **沉浸式体验**：首页/文章列表/关于/留言采用全屏沉浸式设计
4. **暗色主题**：全局冷色调机能风，0 圆角设计
5. **毛玻璃系统**：统一的 `backdrop-filter` 模糊效果
6. **动画流畅**：基于 `meta.index` 的前进/后退差异化动画

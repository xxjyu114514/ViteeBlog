# ViteeBlog 样式系统 - AI 操作守则

> ⚠️ **致所有 AI 助手**：在你修改任何样式文件之前，**必须完整阅读本文档**。
> 任何违反本文档规则的修改，将导致 UI 崩溃、视觉不一致或被立即回滚。

---

## 一、系统架构

```
test_scss/              ← 模块目录（严禁在此目录外创建样式文件）
├── _tokens.scss        ← 设计令牌（颜色、间距、字体 — 唯一修改入口）
├── _glass.scss         ← 毛玻璃系统
├── _buttons.scss       ← 按钮体系
├── _cards.scss         ← 卡片体系
├── _forms.scss         ← 表单体系
├── _typography.scss    ← 文字体系
├── _components.scss    ← 其他组件
└── STYLE_SYSTEM.md     ← 本文档

test_scss.scss          ← 入口文件（只做 @import，不写样式）
test_scss.vue           ← 展示页面（只写 HTML 结构，不写样式）
```

### 核心规则

> **设计令牌在 `_tokens.scss`，组件样式在各模块文件，HTML 在 `.vue`。**
> 这三层禁止跨层。不允许在 `.vue` 里写 `<style>`，不允许在 `_tokens.scss` 里写组件样式。

## 二、红线规则（违反即回滚）

### 🔴 红线 1：禁止全局覆盖

```scss
/* ❌ 绝对禁止 — 之前犯过的错误 */
* { border-radius: 0 !important; }
```

所有作用域限制必须写在 `.test-page {}` 内部。如果要对特定组件取消圆角，在该组件的 class 上操作，永远不要全局覆盖。

### 🔴 红线 2：禁止添加新颜色变量

`_tokens.scss` 中现有的 8 个品牌色 + 4 个灰阶 + 5 个玻璃色已经足够。如果需要"新的颜色"：

1. 先检查现有颜色中是否有接近可用的
2. 如果确实需要新增，必须在文件顶部注明理由和用途
3. **禁止**在模块文件中用硬编码色值（如 `#ff6600`）— 所有颜色必须走变量

### 🔴 红线 3：禁止改变间距基准

间距系统固定为 **8px 基准**（`$space-xs: 8px`）。不允许出现 `13px`、`17px`、`22px` 这种不规则的间距值。必须使用预定义的间距变量。

### 🔴 红线 4：禁止修改 `_tokens.scss` 中的背景亮度阶梯

```
$bg-base:    #0a0a0c    ← 最底层（不可变）
$bg-surface: #111114    ← 面板（不可变）
$bg-elevated:#1a1a1f    ← 悬浮层（不可变）
$bg-hover:   #24242b    ← hover 状态（不可变）
```

这 4 层背景的亮度差必须保持递增（每层约 +6 亮度值）。破坏这个阶梯会导致所有卡片、面板、表单的视觉层次坍塌。

### 🔴 红线 5：禁止改动模块拆分结构

- `_glass.scss` 只写毛玻璃相关
- `_buttons.scss` 只写按钮
- `_cards.scss` 只写卡片
- 依此类推

如果感觉"不知道该放哪个文件"，说明这个组件不应该存在。

### 🔴 红线 6：所有新按钮必须继承 `.btn`

```scss
/* ✅ 正确 */
.btn-my-new-type { @extend .btn; ... }

/* ❌ 禁止 */
.my-new-type { ... }  /* 不与按钮体系继承，会样式断裂 */
```

## 三、设计原则

### 3.1 冷色调主次分明

```
主色（~80% 面积）: 冰蓝 #4ea8de
辅色（~15% 面积）: 冷紫 #6c5ce7
点缀（~5% 面积） : 青绿 #00cec9
暖色（警告/错误） : 仅在必要时出现
```

不要在一个界面上同时使用 3 种以上的色相。

### 3.2 文字对比度标准

| 层级 | 色值 | 对比度(黑底) | 用途 |
|------|------|-------------|------|
| 主要 | `#f0f0f0` | ~15:1 | 标题、正文 |
| 次要 | `#a0a0b0` | ~7:1 | 描述、辅助信息 |
| 三级 | `#7a7a8a` | ~5:1 | 元数据、时间戳 |
| 禁用 | `#484852` | ~3:1 | 禁用状态 |

不要试图让三级文字"更明显"——它的设计意图就是退后。

### 3.3 毛玻璃使用规范

毛玻璃（`backdrop-filter: blur`）只用于**背景图之上的叠加层**。在没有背景图的区域（如当前的测试页），毛玻璃效果在视觉上看起来和普通半透明背景没有区别。

当你以后添加二次元背景图后，毛玻璃效果会自动生效。当前测试页的 `glass-showcase` 区域用渐变色模拟了背景图效果——这是为了方便预览，**不是让你删除它**。

### 3.4 禁用 `!important`

除了 `.loading-spinner` 的 `border-radius`（因为被作用域覆盖），**任何地方不允许使用 `!important`**。

## 四、如何正确修改

### 4.1 新增一个组件

1. 在 `_components.scss` 中写样式（如果是一类新组件，新建 `_xxx.scss` 并在入口文件引入）
2. 在 `test_scss.vue` 中添加对应的 HTML 展示
3. 编译验证：`npm run build` 无报错

### 4.2 调整颜色

只在 `_tokens.scss` 中改变量值。改完后检查所有使用了该变量的组件是否仍然协调。

### 4.3 添加按钮变体

在 `_buttons.scss` 的 `.btn` 块内添加 `&.btn-xxx {}`，不要在外面写一个新的独立类。

## 五、历史教训（避免重犯）

| 问题 | 后果 | 如何避免 |
|------|------|----------|
| `border-radius: 0 !important` 全局覆盖 | 导致全站所有组件圆角强制归零，与项目现有样式冲突 | 作用域限制到 `.test-page` |
| 阴影用 `rgba(0,0,0,x)` | 在纯黑背景上完全不可见 | 暗色主题必须用发光效果（glow） |
| `$text-tertiary: #555` | 对比度仅 ~3:1，用户看不清 | 遵守文字对比度标准 |
| 8 种颜色平等使用 | 页面杂乱无重点 | 冷色调三级体系：80%-15%-5% |
| 960 行写在一个文件 | 难以维护、难以查找 | 分模块，每个文件 <400 行 |
